01

国产32位RISC-V EC

LS101x系列产品是凌思微电子专为便携式计算平台设计的嵌入式控制（EC）芯片，其搭载32位RISC-V内核，主频144MHz，具有多种接口和安全加密功能。支持全系列的Intel（包括MTL平台）、AMD以及主流国产CPU。并且高度兼容市场主流EC应用方案，可内嵌多种新型外设，推动EC方案创新和应用拓展，满足更多市场需求。其广泛适用于各类便携式智能设备，如轻薄笔记本电脑、高性能游戏本等。

  • 32-bit RISC-V
  • 支持LPC/eSPI
  • 安全加密功能
  • 开发工具支持
  • 自主专利/SDK
  • 适配100+机型

出色的硬件特性

  • RISC-V 内核
  • 144MHz 主频
  • 128KB SRAM
  • 111个可配置GPIO
  • 支持1.8V/3.3V电源域
  • 66MHz高速eSPI
  • 多种硬件加密模块

丰富的SDK方案

  • 自主SDK框架
  • 适配各类笔电外设: Charger、PD、Battery、Keyboard、Fan、LED
  • Keyboard高度模块化
  • 支持安全启动
  • 多种OTA方法及Mirror的支持

高效的开发工具

  • EFI下EC固件升级
  • 成熟的上位机调试
  • 完善的产测工具支持
  • 多种烧录及调试方法
  • 自研的I²C DBG调试
  • 完整的EVK评估套件

关键技术自主可控

  • 10+ EC相关专利
  • 100+ 机型成功适配
  • 核心IP自主研发
  • EC SDK自主可控

技术参数

系统主机接口

  • eSPI接口
    • 支持Peripheral通道
    • 支持Virtual Wire通道
    • 支持OOB message通道
    • 支持Flash access通道
    • 支持20~66MHz通信速率
  • LPC接口
    • LPC接口IO访问（16位地址， 8位数据）
    • LPC接口存储器访问（32位地址， 8位数据）
    • 支持PCI系统串行IRQ规范6.0版
    • 支持SERIRQ
  • 支持端口80 BIOS调试
  • Share Memory
    • 最多16个窗口
    • 每个窗口最多1024Bytes的内存
  • 主机UART调试
  • 支持ACPI规范
  • 支持端口62/66、 60/64、 68/6C、 4E/4F
  • 支持PECI
  • 8042模拟键盘控制器
    • 8042型主机接口
    • PS/2 Set1或Set2 scan code
  • 支持8×18键盘矩阵
  • 支持邮箱功能
  • 支持电源管理通道（PMC）
  • 支持笨电池、智能电池和智能风扇

RISC-V嵌入式处理器

  • 最高主频144MHz
  • 支持RISC-V RV32IMAFC[P]指令集
  • 支持RISC-V 32/16位混合指令集
  • 支持RISC-V机器模式和用户模式

内存

  • 128KB SRAM
  • 16KB启动ROM
  • 支持高达512KB的Flash

系统外设

  • 2个DMA控制单元
    • 12路DMA传输通道
  • 最多6路I²C通信接口(兼容SMBus/PMBus)
  • 最多4路PS/2接口
  • ·USB2.0全速通信接口
  • 最多8路PWM接口
  • 最多8路风扇转速计
  • 最多5路UART通信接口
  • 最多3路SPI通信接口（主/从）
  • 支持CEC通信接口
  • 支持OneWire接口

电源&功耗

  • 支持PC平台5种ACPI电源状态
  • 支持多种睡眠模式

模拟外设

  • 2个12位SAR-ADC
    • 支持16路外部输入通道
    • 支持ADC模拟看门狗功能
    • 支持芯片温度监测功能
    • 支持外部电压参考
  • 2个12位DAC

安全算法

  • 支持eRPMC
  • 公钥密码算法（ECC/SM2）
  • 摘要算法（SHA256/SM3）
  • 分组密码算法（AES/DES/SM4）
  • 循环冗余校验码（CRC）

电压&温度

  • 工作电压： 2.9V < VDD < 3.6V
  • 工作温度： -40℃至85℃

封装

  • LQFP-128（14×14mm）
  • VFBGA-128（7×7mm）

调试工具

  • ECLink
  • 串口工具
