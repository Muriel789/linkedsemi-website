CAREERS AT LINKEDSEMI

招聘简章

虚位以待，“职”为您；携手凌思，成就梦想！

梦想之行始于 LinkedSemi，LinkedSemi 与您共筑辉煌。我们期待与热爱芯片设计、无线连接和智能应用的伙伴一起成长。

BENEFITS

相关福利待遇

厦门可申请人才、毕业生等相关补贴。提供弹性上班时间、五险一金、年终奖金、灵活调薪、办公室点心、交通补贴和加班餐补。

01应用（AE / FAE）工程师上海 / 北京 / 深圳 · 5年以上＋
工作地点上海 / 北京 / 深圳招聘人数若干职位类别研发类工作年限五年以上学历要求本科所属部门研发部薪酬范围面议职位发布长期

岗位描述

  1. 为客户搭建测试及开发环境，熟练解决开发板和 SDK 套件连接的各种问题。
  2. 基于公司蓝牙等 SoC 芯片完成完整方案设计开发，并支持客户方案导入、量产。
  3. 客户需求研究和导入，定义产品需求并研究实现的可行性。
  4. 开发并维护软/固件、设备驱动和应用软件并保证质量。
  5. 客户系统应用问题和解决。
  6. 对设计工作和测试数据存档。
  7. 紧密并高效地与团队成员和硬件设计团队协作。

岗位要求

  1. 电子、计算机类（或相关专业）本科及以上。
  2. 大学优秀毕业生或 1 年以上的嵌入式系统软件设计经验，尤其底层软件驱动开发经验。
  3. 具有较强的软件平台搭建能力，包括软件/固件环境、软件工具设置。
  4. 具有扎实的 C 编程技能，熟悉 Keil / VS Code 等开发环境。
  5. 在校期间参加电子设计大赛并获奖者或熟悉低功耗蓝牙者优先。
  6. 良好的沟通技巧、团队合作以及自我驱动精神。

02芯片验证工程师上海 · 5年以上＋
工作地点上海招聘人数若干职位类别研发类工作年限五年以上学历要求本科所属部门研发部薪酬范围面议职位发布长期

岗位描述

  1. 公司研发芯片测试平台程序开发和维护。
  2. 新研发样片测试计划定制、测试、总结及完成测试报告。
  3. 负责芯片测试相关 PCB 设计及 layout。
  4. 协助 AE/FAE 进行客户应用问题或 bug 的验证与分析。
  5. 部分芯片驱动的开发和维护。
  6. 解决芯片相关量产芯片的功耗、功能、性能、生产和兼容性等问题。

岗位要求

  1. 计算机、电子或微电子相关专业本科学历。
  2. 熟悉 C 语言编程，熟悉 Keil / VS Code 等开发环境。
  3. 在校期间参加电子设计大赛并获奖者或熟悉低功耗蓝牙者优先。
  4. 良好的沟通技巧、团队合作以及自我驱动精神。

03软件 / 固件工程师上海 / 北京 / 深圳 · 1年以上＋
工作地点上海 / 北京 / 深圳招聘人数若干工作年限一年以上学历要求本科及以上

岗位描述

  1. 软/固件技术需求分析，软件系统或子系统设计，用合适的工程技巧编写代码或测试。
  2. 定义产品需求并研究实现的可行性。
  3. 开发并维护软/固件、设备驱动和应用软件并保证质量。
  4. 对设计工作和测试数据存档。
  5. 紧密并高效地与团队成员和硬件设计团队协作。

岗位要求

  1. 电子、计算机类（或相关专业）本科及以上学历。
  2. 1 年以上嵌入式系统软件设计经验，尤其底层软件驱动开发经验。
  3. 具有较强的软件平台搭建能力，包括软件/固件环境、软件工具设置。
  4. 具有扎实的 C 编程技能，熟悉汇编语言。
  5. 熟悉低功耗蓝牙者优先。
  6. 熟悉调试和测试嵌入式软件。
  7. 熟悉软件配置和版本控制。
  8. 具备良好英文书写能力及文档阅读能力。
  9. 具备良好沟通技巧、团队合作及自我驱动精神。

04射频 IC 设计工程师上海 · 本科及以上＋
工作地点上海招聘人数若干学历要求本科及以上

岗位描述

  1. 建模、电路设计、电路前仿真和后仿真。
  2. 指导版图设计工程师完成高质量的版图设计。
  3. 协助测试工程师开发 ATE 测试程序。
  4. 协助产品工程师达到生产制造要求。
  5. 协助应用工程师达到客户要求。
  6. 细化说明书，支持内部、外部用户，如应用工程师等。

岗位要求

  1. 微电子、电子工程等相关专业，本科及以上学历。
  2. 熟悉模拟和数字电路知识，了解半导体物理、器件和工艺。
  3. 熟练掌握模拟和数字电路设计软件，熟悉版图设计和验证（DRC、LVS、PEX）。
  4. 有 ADC、DAC、OPAMP、DC-DC、LDO、Bandgap/OSC 等流片经验者优先；有 transceiver 设计经验者优先；有先进工艺流片经验者优先。
  5. 熟练使用 Cadence Spectre 等 EDA 设计工具；熟练使用示波器、频谱仪、网络分析仪、信号源等仪器。

05模拟 IC 设计工程师上海 · 本科及以上＋
工作地点上海招聘人数若干学历要求本科及以上

岗位描述

  1. 建模、电路设计、电路前仿真和后仿真。
  2. 指导版图设计工程师完成高质量的版图设计。
  3. 协助测试工程师开发 ATE 测试程序。
  4. 协助产品工程师达到生产制造要求。
  5. 协助应用工程师达到客户要求。
  6. 细化说明书，支持内部、外部用户，如应用工程师等。

岗位要求

  1. 微电子、电子工程等相关专业，本科及以上学历。
  2. 了解 MOS 制程、器件物理及建模知识。
  3. 有以下经验者优先：
    • active-rc 滤波器、delta-sigma modulator、SAR ADC、DAC、PLL、DC-DC 转换器等。

    • 熟悉 Matlab/Simulink、Verilog、Verilog-A、Verilog-AMS 建模。
    • 熟悉 Cadence 工具（Virtuoso、ADE 等）及 SPICE、Spectre、SpectreRF 等模拟工具。
    • 熟悉逻辑分析仪、示波器等各种测试仪器。

06ATE 测试工程师上海 · 专科及以上＋
工作地点上海招聘人数若干学历要求专科及以上

岗位描述

  1. 负责量产产品测试程序维护，CP/FT 程式升级、变更、转厂验证及管理。
  2. 负责工厂硬件维护及产线异常处理，包含针卡、Loadboard、socket 等。
  3. 协助测试产品失效分析、客退/客诉异常片品的处理分析，配合可靠性工程师进行可靠性测试及对应数据分析。
  4. 负责日常量产测试数据汇总、整理及分析，量产产品良率跟踪及 low yield 处理。

岗位要求

  1. 半导体、微电子、通信、自动化等相关专业专科及以上学历。
  2. 熟悉 ATE 测试等相关知识，熟悉 CP/FT 测试基本原理和流程；熟悉至少一种主流测试平台（Chroma、93K、J750 尤佳）。
  3. 具备统计分析及较强的逻辑思维、数据分析能力，熟悉 Perl/Python 尤佳。
  4. 具有良好的沟通能力、分析问题能力、协调能力及团队合作精神。
投递该岗位 ↗
07数字验证工程师上海 · 本科及以上＋
工作地点上海招聘人数若干学历要求本科及以上

  4. 具有良好的沟通和协调能力，较强的团队意识及合作精神。
