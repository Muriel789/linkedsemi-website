01

MESH组网

蓝牙mesh网络是用于建立多对多设备通信的低功耗蓝牙网络拓扑结构。在如今，蓝牙适用的范围已经逐渐拓展到所有物联网边缘场景：“蓝牙增强速率技术（BR / EDR）” 的应用从无线耳机发展到鼠标键盘；“蓝牙低功耗技术” 应用于手表、手环，发掘了可穿戴市场；而“蓝牙 Mesh 组网技术”则瞄准了整个（边缘域）物联网市场，包括消费领域和工业领域。

05

SIG Mesh

LinkedSemi一直致力于研发 BLE-MESH-SDK，开发的蓝牙 Mesh 核心功能通过了 蓝牙技术联盟（Bluetooth SIG）全功能支持 的认证。全面支持 蓝牙 Mesh 协议 规定的所有 Core Features、Client Models 和 Server Models，而且通过蓝牙 Mesh 所有的认证测试项测试。未来，我们将在BLE-MESH上联合合作伙伴一起开发出更多的有趣的产品。欢迎大家一起来探索更广阔的应用场景。

06

天猫 Mesh

天猫精灵作为阿里巴巴家庭大脑的 AI 中枢，也是阿里巴巴未来AIOT生态打造的最重要的入口。LinkedSemi 作为阿里巴巴的深度合作芯片厂商，旗下两个系列芯片：LE5010和LE5030 已经率先接入天猫精灵的Mesh 协议。在天猫精灵生态中，实现智能家居场景对接，涉及到产品类型智能窗帘，智能灯，智能面板，智能水杯，智能电毯等应用。LinkedSemi天猫精灵蓝牙Mesh方案，除了支持通过智能音箱以语音近场控制用户产品外，也能通过手机天猫精灵APP进行远程控制，在价格、安全性、功耗、配网方式等方面具有明显的优势。

07

私有 Mesh

Linkedsemi在支持标准的SIG MESH基础上，并支持定制的私有MESH协议。充分利用BLE5.x的特性，突破SIG MESH空中单包有效数据量，减少大数据拆包带来的时延，减少多层加密处理的延时，表现出响应时间快，实现场景多等优势。为了构建和完善一个适合低功耗的物联网生态，将进一步完善对市面上各种厂商定制的私有mesh统一和规范通讯协议。并且提供了完整的应用解决方案，减少客户的二次开发。
